## 3zT Agent 2.0

- One installer: Python, ffmpeg, yt-dlp, Node.js, llama.cpp (CUDA) and Real-ESRGAN are built in. No Ollama, no separate setup scripts.
- New uncensored agent: Inkling 2 Mini Uncensored with vision, a fast in-VRAM build and an optional quality build that uses system RAM safely.
- Setup & downloads screen: models and add-ons download from inside the app with progress and resume.
- New skills: image-director, video-director, ffmpeg-skill, HyperFrames, agent-browser, ponytail.
- Saudi dialect enforcement with automatic rewrite.
- Arabic/English mixed text keeps its order everywhere.
- Hard limits are enforced by the app before every generation (all text fields, Arabic word matching).

Upgrading from 1.x: install, open the app, download the models from Settings → Setup & downloads. The old Ollama models can be removed from the same screen.
